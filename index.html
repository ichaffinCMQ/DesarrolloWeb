Bienvenidos al Curso de Tester de Aplicaciones

Para aprender las bases del testing.

¿Qué vas a aprender?

  • Introducción al testing manual

    • El testing manual es el proceso de verificar y validar el funcionamiento de una aplicación de forma manual, sin el uso de herramientas automatizadas. El objetivo principal es identificar errores, defectos o comportamientos inesperados en el software antes de que llegue al usuario final.

  • Diseño de casos de prueba

    • El diseño de casos de prueba es el proceso de crear escenarios específicos que se utilizarán para evaluar el comportamiento del software. Estos casos de prueba deben ser claros, concisos y cubrir diferentes aspectos del sistema.

  • Gestión de bugs y herramientas de seguimiento

    • La gestión de bugs implica registrar, clasificar y hacer seguimiento a los errores encontrados durante el proceso de testing. Las herramientas de seguimiento permiten a los equipos colaborar y mantener un registro de los problemas identificados.

  • Uso de Jira, TestLink, Azure DevOps

    • Estas son herramientas populares utilizadas en la gestión de proyectos y pruebas de software. Jira es una herramienta de seguimiento de problemas y gestión de proyectos, TestLink es una herramienta de gestión de pruebas y Azure DevOps es una plataforma completa para la colaboración en el desarrollo de software. En la seccion de materiales podrás descargar los instaladores de estas herramientas.
